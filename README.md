# E27 IR Remote

Aplikasi remote inframerah untuk menyalakan dan mematikan fitting lampu melalui ponsel Android. Ponsel harus memiliki pemancar inframerah (IR blaster) bawaan. Aplikasi dapat digunakan secara offline tanpa koneksi internet.

**[Unduh E27 IR Remote APK](https://github.com/Steventan10/E27-IR-Remote/raw/9fb4a6af92b8a8b4e4de4670aedc82a0d721d36c/E27_IR_Remote.apk)**

## Fitur

- Menyalakan dan mematikan fitting lampu TaffLED E27.
- Mengirim perintah ON/OFF melalui tombol di aplikasi.
- Mengakses toggle ON/OFF dari panel **Quick Settings / Pusat Kontrol** Android.
- Mengakses pintasan **ON** dan **OFF** dengan menekan lama ikon aplikasi.

## Cara menggunakan

1. Unduh dan instal APK melalui tautan di atas.
2. Arahkan pemancar inframerah ponsel ke penerima IR pada fitting lampu.
3. Tekan **ON** untuk menyalakan lampu atau **OFF** untuk mematikannya.

Untuk akses dari Pusat Kontrol, buka panel Quick Settings, pilih **Edit**, lalu tambahkan tile aplikasi. Ketuk tile untuk mengirim perintah ON/OFF secara bergantian. Tampilan panel dan nama menu dapat berbeda pada setiap ponsel.

Untuk akses dari layar utama, tekan lama ikon aplikasi, lalu pilih pintasan **ON** atau **OFF**. Fitur ini memerlukan launcher yang mendukung pintasan aplikasi.

> Status toggle mengikuti perintah terakhir yang dikirim aplikasi, bukan pembacaan kondisi lampu secara langsung.
